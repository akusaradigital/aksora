Dokumentasi Arsitektur AI & Manajemen API Keys

Panduan alur menyeluruh (end-to-end), spesifikasi teknis, mekanisme proteksi, dan rincian fungsi pada modul Manajemen API Keys dan AI & Model Settings (termasuk integrasi adaptif 9Router).

Latar Belakang & Perubahan Utama

  • Redesain Layout Modal API Keys: Mengganti modal kaku dengan dialog fleksibel ModalShell berstandar visual Aksora (rounded-2xl, sentence case, segmented access level, permission selector).
  • Eliminasi AI Purple Slop: Membersihkan palet warna ungu generik; mengadopsi standar biru Aksora (#2563eb), hijau status aktif (#059669), dan slate netral.
  • Perbaikan Status Gemini False-Active: Indikator aktif kartu dan badge kini terikat penuh pada validasi koneksi riil (isCardActive = isConnected && isActive).
  • Dynamic Model Catalog: Pengambilan katalog model langsung secara live via API provider, didukung caching lokal dan mode model custom.
  • Universal 9Router Deserializer: Penanganan multi-format respon proxy (6 varian) dan dual-host fallback (127.0.0.1 ↔ localhost).

C. Alur Eksekusi Pemanggilan AI (callLLM) dengan 9Router Failover

Mekanisme fallback otomatis saat modul fitur (Sicmundus task generator, QA test generation) memanggil engine LLM:

sequenceDiagram
    autonumber
    participant App as Aksora Feature (Task/QA/Report)
    participant Lib as lib/ai-service (callLLM)
    participant R1 as 9Router (127.0.0.1:20128)
    participant R2 as 9Router (localhost:20128)
    participant Ext as Cloud Provider (Google/OpenAI/etc)

    App->>Lib: callLLM({ provider, model, prompt })
    alt Provider = 9Router (Lokal)
        Lib->>R1: POST http://127.0.0.1:20128/v1/chat/completions
        alt Respon 200 OK
            R1-->>Lib: Stream / Completion Result
        else Connection Refused / Timeout
            Lib->>R2: Failover POST http://localhost:20128/v1/chat/completions
            R2-->>Lib: Stream / Completion Result
        end
    else Cloud Provider
        Lib->>Ext: POST API Endpoint Provider Resmi
        Ext-->>Lib: Completion Result
    end
    Lib-->>App: { content, totalTokens, provider, model }

3. Arsitektur Keamanan & Proteksi Data

Client-Side Credential Vault

Semua token API pihak ketiga (Gemini, OpenAI, Anthropic, Groq, DeepSeek, 9Router) disimpan eksklusif di browser lokal pengguna melalui localStorage dengan enkripsi rolling TTL 14 hari. Kredensial tidak pernah disimpan di database Postgres server.

Proteksi SSRF (Server-Side Request Forgery)

URL endpoint publik 9Router (misal Cloudflare Tunnel) wajib divalidasi oleh validateOutboundUrlAsync() di lib/ssrf-guard.ts untuk mencegah manipulasi loopback internal, private IP ranges (RFC 1918), atau port sniffing.

4. Spesifikasi Resilient Parser 9Router

Models Envelope (String) {"models": ["mistral-large"]} ["mistral-large"]
