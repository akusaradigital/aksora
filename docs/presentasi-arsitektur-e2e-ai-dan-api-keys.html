SLIDE 03 Alur REST API Key Management

Flow E2E: Pembuatan Aksora API Key

Alur pembuatan personal access token untuk integrasi eksternal (CI/CD, automated test, dan script).

1
Trigger & Pembukaan Modal Dialog UI: components/ui/modal-shell.tsx

Pengguna mengklik tombol Create New API Key di /settings/api-keys. Dialog ModalShell muncul dengan animasi zoom-in 95% dan backdrop blur halus.

2
Konfigurasi Hak Akses Granular app/settings/api-keys/api-keys-client.tsx

Pengguna menentukan nama key, masa kedaluwarsa (30, 90, 365 hari, atau unlimited), memilih Read & Write vs Read-only secara visual, serta memilih modul yang diizinkan (Tasks, Bugs, Test Cases, dll) dengan tombol pintas Select All / Deselect All.

3
Hashing & Penyimpanan Aman Server Backend: POST /api/settings/api-keys

Server men-generate token dengan format aksora_live_.... Token di-hash menggunakan algoritma SHA-256 sebelum disimpan ke PostgreSQL. Hanya prefix (contoh aksora_live_a1b2...) yang disimpan sebagai identifikasi publik.

4
One-Time Secret Reveal Modal Security Principle

Modal kedua terbuka menampilkan raw secret key sekali-lihat lengkap dengan tombol Copy instan. Setelah jendela ditutup, raw key tidak dapat dipulihkan kembali.

Flow E2E: Client-Side AI Vault & Live Validation

A
Inisialisasi Bersih (Zero False-Active) lib/ai-keys.ts: getActiveAiConfig()

Ketika browser membuka halaman /settings/ai, sistem mengecek getActiveAiConfig(). Jika pengguna belum pernah mengaktifkan provider, fungsi mengembalikan { provider: "", model: "" }. Tidak ada provider yang otomatis di-highlight ungu / aktif secara sepihak.

B
Validasi Real-time & SSRF Inspection app/api/ai/validate/route.ts

Saat user memasukkan kredensial dan klik Test & Save, route server melakukan healthcheck langsung ke endpoint API provider. Khusus 9Router Public, validateOutboundUrlAsync() mencegah injeksi loopback atau private subnet internal.

C
Aktivasi Terverifikasi (Strict State Machine) components/settings/ai-settings-client.tsx

Hanya setelah status menjadi connected atau saved, tombol Use as Active dapat ditekan. Kartu yang aktif ditandai border biru resmi Aksora (border-blue-500 ring-2 ring-blue-500/10) dan badge Active.

SLIDE 05 Deep-Dive: 9Router Ecosystem

9Router Resilient Parsing & Dual-Host Failover

Menjamin semua jenis model dari 9Router dapat terbaca mulus baik pada port daemon lokal maupun Cloudflare tunnel.

Parser extractModelsFromPayload()

Fungsi universal di lib/ai-service.ts yang menangani 6 format respon varian 9Router:

Format yang Didukung:
1. OpenAI standard: {"data": [{"id": "..."}]}
2. String data array: {"data": ["model-1"]}
3. Models envelope: {"models": [{"id": "..."}]}
4. Models string array: {"models": ["model-1"]}
5. Items envelope: {"items": [{"id": "..."}]}
6. Direct root array: [{"id": "..."}] / ["..."]
Network Failover queryLocal9Router() & callLLM()

Menyelesaikan masalah socket binding pada Windows / Linux (IPv4 vs IPv6 ::1):

Urutan Discovery Sekuensial:
1. http://127.0.0.1:20128/v1/models
2. http://localhost:20128/v1/models
3. http://127.0.0.1:20128/models
4. http://localhost:20128/models
⚡ Chat completions di callLLM() otomatis retry ke localhost jika 127.0.0.1 ditolak!
SLIDE 06 Technical Reference

Kamus Lengkap Fungsi & Komponen

Daftar fungsi inti yang dibangun dan dioptimalkan beserta perannya dalam arsitektur sistem.

Berkas Nama Fungsi Input & Return Logika Bisnis & Edge Cases
components/ui/modal-shell.tsx ModalShell Props: isOpen, onClose, title, ... Komponen dialog serbaguna: backdrop blur, ESC keydown listener, CSS transition 150ms, header Phosphor icon.
lib/ai-keys.ts getActiveAiConfig() () => { provider, model } Mengembalikan provider & model aktif. Zero-default (menghilangkan default paksa Google Gemini).
lib/ai-keys.ts getApiKey() / setApiKey() (p, key?) => string / void Penyimpanan browser local vault dengan masa aktif TTL 14 hari rolling expiration. Kredensial tidak menyentuh database.
lib/ai-keys.ts getStoredProviderModels() (provider) => string[] Membaca cache model yang berhasil di-fetch secara dinamis dari API resmi provider.
lib/ai-service.ts extractModelsFromPayload() (data: unknown) => string[] Deserializer 6 varian respon 9Router & OpenAI proxies. Mengabaikan ID kosong dan me-normalize whitespace.
lib/ai-service.ts queryLocal9Router() (key?, timeout?) => Promise Pemeriksaan otomatis port 20128: mencoba IPv4 (127.0.0.1) dan localhost (IPv6/IPv4) pada rute /v1/models dan /models.
lib/ai-service.ts queryPublic9Router() (url, key?, timeout?) => Promise Pemeriksaan endpoint Cloudflare Tunnel publik dengan normalisasi URL dan rute model.
lib/ai-service.ts callLLM() (opts: CallLLMOptions) => Promise Universal LLM executor (Gemini, Claude, OpenAI-compatible). Memiliki automatic localhost retry untuk 9Router.
SLIDE 07 Kesimpulan & Standar Tim

Rangkuman & Panduan Pengujian Tim

Hal-hal yang perlu diketahui tim engineering untuk memverifikasi dan menggunakan fitur ini.

QA Checklist Pengujian Fitur
  • Buka /settings/api-keys: Buat key baru, pastikan modal tampil rounded-2xl dan sentence-case.
  • Buka /settings/ai: Pastikan saat pertama kali dibuka, Google Gemini TIDAK menyala aktif.
  • Klik tombol Fetch Models: Pastikan model terbaru di-query langsung dari endpoint provider resmi.
  • Jalankan 9Router lokal di port 20128: Pastikan Aksora langsung mendeteksi model lokal tanpa konfigurasi manual.
Security Standard Keamanan Data & Privasi
  • Zero-DB Vault: Kredensial AI tidak pernah dicatat dalam log server maupun disimpan di database Postgres.
  • SSRF Hardening: Semua URL tunnel publik diuji melalui validateOutboundUrlAsync().
  • API Key Hashing: Kredensial Aksora API Key di-hash dengan SHA-256; token rahasia hanya tampil 1 kali.
